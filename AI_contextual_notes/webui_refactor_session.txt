PROBLEM SUMMARY
---------------
The Activity Feed and Live Log Viewer on the Activity tab are not working because:
1. The log file (/config/logs/f1.log) is not being created
2. The F1 scripts (f1_grabber.py, f1_scheduler.py, f1_sort.py, f1_watcher.py) 
   still use legacy per-script logging with logging.basicConfig()
3. They need to be updated to use the new centralized logging from f1_common.py

WHAT HAS BEEN DONE
------------------
1. Added centralized logging functions to f1_common.py (lines 126-303):
   - setup_logging() - initializes the logging system
   - get_logger() - returns a logger in the f1.* hierarchy
   - LogConfig class - configuration singleton
   - Creates rotating log file at /config/logs/f1.log

2. The logging code was adapted from motogp_common.py which works correctly

FOR EACH SCRIPT, THE CHANGES ARE:

A) Update imports - add setup_logging and get_logger:
   
   FROM:
   ```python

   To

B) Remove the old setup_logging() function (each script has its own)

REMOVE code like this:
def setup_logging():
    """Setup logging configuration."""
    log_dir = Path("/config/logs")
    log_dir.mkdir(parents=True, exist_ok=True)
    log_file = log_dir / "f1_scheduler.log"
    
    logging.basicConfig(
        level=logging.INFO,
        format='%(asctime)s - %(name)s - %(levelname)s - %(message)s',
        handlers=[
            logging.FileHandler(log_file),
            logging.StreamHandler()
        ]
    )
    return log_file
C) Add module logger and init function:

ADD after imports:
# Module logger - will be configured by init_logging()

def init_logging(verbose: bool = False):
    """Initialize logging for this script."""
    setup_logging(debug_mode=verbose)
    logger.info("F1 Scheduler initialized")  # adjust message per script

D) Update main() to call init_logging():

CHANGE:
def main():
    log_file = setup_logging()
TO:
def main():
    init_logging()

E) Replace any logging.info/debug/error calls with logger.info/debug/error:

CHANGE: logging.info("message")
TO: logger.info("message")
